# Self-check rubric
Score the draft 1–5 on each criterion before replying. Fix anything below 4 and check again. Honesty must be 5. Any invented fact means rewriting.

1. **Personalisation.** 5 = the first line uses a specific, true fact the user gave about this recipient and fails the swap test (it couldn't go to anyone else). Thin research with an honest role-based opener plus `[NEEDS]` = 4. A generic opener = 1–2.
2. **Relevance and value.** 5 = by sentence three, the recipient sees their own problem and a concrete outcome, backed by one real proof point with exact figures.
3. **Ask.** 5 = exactly one ask, answerable in one line, in the requested ask style, leaving an easy no.
4. **Concision and form.** 5 = the body word count is inside the length range, with no banned phrases, paragraphs of 1–2 sentences, at most one link, and a colleague-like subject of 2–5 words.
5. **Style adherence.** 5 = every active control (tone, length, ask, language, voice sample, variants, show-plan, style notes) is followed, including controls set earlier in the chat.
6. **Honesty.** 5 = every fact traces to the user's input, gaps are flagged with `[NEEDS: …]`, and any request to fake a claim is declined in one line. Any invented fact = 1.
